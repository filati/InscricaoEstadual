======================================================================
 INSCRIÇÃO ESTADUAL — MATO GROSSO DO SUL (MS)
======================================================================

Fonte oficial: Sintegra
http://www.sintegra.gov.br/Cad_Estados/cad_MS.html


FORMATO
----------------------------------------------------------------------
- Tamanho: 9 dígitos (8 da base + 1 verificador).
- Os dois primeiros dígitos são 28 ou 50.


CÁLCULO DO DÍGITO VERIFICADOR
----------------------------------------------------------------------
Método: módulo 11.
Pesos (esq.→dir.): 9 8 7 6 5 4 3 2 (sobre os 8 dígitos base).

Passos:
  1. Some os produtos dígito × peso.
  2. R = soma % 11.
  3. Se R = 0, DV = 0.
  4. Senão T = 11 - R: se T > 9, DV = 0; caso contrário, DV = T.


EXEMPLO
----------------------------------------------------------------------
IE: 280000006
  Base: 2 8 0 0 0 0 0 0  →  soma = 82, R = 5, T = 6  →  DV = 6


OBSERVAÇÕES
----------------------------------------------------------------------
- O roteiro oficial não traz exemplo numérico; o exemplo acima foi
  construído aplicando o algoritmo.
